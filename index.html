I don't think discipline is a mood. It's infrastructure — something you build once, in the boring moments, so it never has to be negotiated with again.

That's the operating principle behind everything on this page. An agency, a research channel, and a supplement brand aren't three separate bets — they're the same practice, run three times, in three different materials.
